Монтаж с ИИ

ИИ-агент монтирует кодом: сцены — HTML, правка — строка в скрипте. Шесть упражнений, что получилось и какие правила остались.

Главное за минуту
  • Ролик — это скрипт: список планов в Python, правка — одна строка и повторный рендер.
  • Склейка на такт музыки, первый кадр — обложка, текст только в безопасной зоне.
  • Каждый рендер измеряют: громкость −14…−16 LUFS, пик ≤ −1 dB, у петли — стык.

Монтажёр из кода: HyperFrames

HyperFrames (HeyGen, Apache-2.0, бесплатно) собирает видео из HTML: каждая сцена — это страница с анимацией на GSAP, а headless Chrome и FFmpeg рендерят её кадр за кадром в MP4. Для ИИ-агента это удобнее монтажки с таймлайном: правка — это одна строка в скрипте и повторный рендер. Плюс есть библиотека из ~450 готовых блоков: субтитры, плашки, карточки подписки, фоны.

В серии 10 ИИ-агент (Claude) смонтировал шесть упражнений, от простого к сложному. Всё считается на процессоре, видеокарта остаётся свободной. Рендер занимает 20–100 секунд на ролик.

шаг 1 · сценарийскрипт make_*.pyсписок планов/сцен в Python → index.html и под-композиции
шаг 2 · проверкаcheck + snapshotлинтер ловит мелкий текст, «мёртвые» паузы, дёргающиеся анимации; снимки кадров на стыках
шаг 3 · рендерrender + замерыгромкость (LUFS), стыки петель, копия для телефона

Вертикальный ролик 9:16 с музыкой

Четыре H3-ролика «Выходной Марен» (768×960) перемонтированы в вертикаль 1080×1920 на 24 секунды. Десять планов, каждая склейка — на границе такта музыки (100 BPM, такт 2,4 с). Хук «my sunday» стоит уже на первом кадре: этот кадр — обложка. Озвучка — Kokoro, субтитры по таймингам whisper, в конце карточка подписки из библиотеки блоков.

  • Музыка своя: ACE-Step 1.5. На арендованной RTX 4090 — 4 секунды на трек длиной 32 с. Сделали восемь вариантов в трёх стилях и выбрали по анализу темпа и громкости по тактам. Трек обрезан так, что его собственная концовка приходится ровно на последний кадр, без затухания.
  • Кадр 4:5 → 9:16: сначала ffmpeg (lanczos) растягивает клип до 1536×1920, потом каждый план выбирает своё окно по горизонтали и медленный наезд. Растягивать вдвое в браузере — мыльно.
  • Текст только в полосе 168–1330 px. Выше и ниже — интерфейс приложения. Нижний край субтитров — в 600 px от низа кадра.

Заставка для стрима: бесшовная петля + отсчёт

Для OBS сделаны два клипа. Петля на 28,8 с (12 тактов) крутится, пока стрим не начался. Отсчёт на 6 с запускается хоткеем: «3·2·1» идут по долям, а на склейке в чёрное звучит удар райзера. Фон собран из готовых блоков: аврора, пульс на каждый такт, звёзды.

  • Петля = целые такты, и каждый слой в конце совпадает с началом. Музыка режется по тактам, а хвост за точкой петли накладывается на начало с плавным переходом (make_loop.py). Громкость меняется только постоянным усилением: обычная нормализация «плавает» и ломает стык.
  • Грабли библиотеки: у фоновых блоков внутри зашита длина 4–6 с, и на 28,8 с они не растягиваются — аврора просто пропадала на 4-й секунде. Нужно вписывать длину при копировании блока.

Объясняющий ролик: что делает LoRA

Шесть сцен по тактам, только реальные данные. Krea 2 Turbo, один сид и один промпт — меняется лишь сила LoRA. LoRA ta86_inkriot весит 229 МБ, это 0,9 % от модели (26,3 ГБ).

Правила, которые остались

  • Ролик — это скрипт, а не HTML руками. Список планов в Python, каждая правка — одна строка и повторный рендер.
  • Сначала библиотека блоков (catalog), потом своя анимация. Блоки сделаны под 1920×1080 — их надо переносить в безопасную зону кадра.
  • Склейка на такт, первый кадр — обложка. В вертикали план идёт 1–2,4 с, ничего не стоит неподвижно дольше 3 с.
  • Текст ≥ 28 px, не больше 4–5 слов в строке. Последняя строка держится на экране ≥ 2 с.
  • Каждый рендер измеряется: громкость −14…−16 LUFS для соцсетей, пик ≤ −1 dB. У петли проверяется стык.
