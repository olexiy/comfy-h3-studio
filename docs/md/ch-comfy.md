# 3. ComfyUI: граф, ноды, workflow

> EN: ComfyUI basics: nodes, typed links (MODEL, CLIP, VAE, LATENT, CONDITIONING, IMAGE), the minimal text-to-image graph, model folders, custom nodes, subgraphs and our one-node workflow style, workflows embedded in PNG/MP4, the HTTP API (/prompt, /history, /object_info, /free), caching and the queue.

ComfyUI — это конструктор: каждая операция — нода, данные текут по проводам. Здесь — как читать любой чужой граф, где ComfyUI ищет файлы и как агент управляет им без мыши.

- Граф читается слева направо: загрузка моделей → текст → сэмплер → декодер → сохранение. Цвет провода = тип данных.
- Модели — в models/<тип>/, кастомные ноды — в custom_nodes/. Нет файла или ноды — граф не запустится.
- Перетащите PNG или MP4, сделанный в ComfyUI, на холст — откроется граф, который его сделал.
- Агент работает через HTTP API: POST /prompt → GET /history. Интерфейс для этого не нужен.

## Что такое ComfyUI

**ComfyUI** — бесплатная программа с открытым кодом для запуска генеративных моделей. Внутри — сервер на Python, снаружи — редактор графов в браузере: каждая операция (загрузить модель, закодировать текст, сделать шаги, сохранить) — отдельная **нода**, данные текут между ними по проводам. Граф целиком называют **workflow**.

Почему не кнопочный сервис: в графе видно и можно поменять всё — модель, LoRA, сэмплер, порядок проходов. Новые модели появляются в ComfyUI в день выхода, часто с официальным шаблоном. А для ИИ-агента граф — это просто JSON, который можно собрать скриптом и отправить на сервер.

| Вариант | Для кого | Заметка |
|---|---|---|
| **ComfyUI Desktop** | Windows и macOS, начало работы | установщик, свой Python внутри, обновления в один клик; на нём сделана вся локальная часть книги |
| Portable / git | Linux, сервер, облако | `git clone` + `pip install -r requirements.txt`; так ComfyUI ставится на арендованную видеокарту за пару минут |
| Comfy Cloud | без своей видеокарты | платная подписка, только поддерживаемые кастомные ноды ([сравнение площадок](ch-studio.html#remote)) |

## Минимальный граф: текст → картинка

Любой граф генерации картинки сводится к девяти нодам. Сравните со [схемой модели](ch-theory.html#th-parts): три загрузчика, два текста (позитив и негатив), пустой латент, сэмплер, декодер, сохранение.

- **Цвет провода = тип данных.** MODEL, CLIP, VAE, CONDITIONING (закодированный текст), LATENT, IMAGE. Провод соединяет только выход и вход одного типа — это и подсказка, и защита от ошибок.

- **Для картинки-в-картинку** пустой латент заменяют на `Load Image → VAE Encode`, а `denoise` в KSampler ставят меньше 1: 0,2 — лёгкая доработка, 0,6 — сильная переделка.

- **Новые модели** часто вместо `KSampler` используют связку `SamplerCustomAdvanced` + отдельные ноды сигм и гайдера, а вместо `CLIP Text Encode` — свой энкодер (например, `TextEncodeQwenImage21`). Логика та же.

## Где ComfyUI ищет файлы

| Папка models/… | Что в ней | Пример из книги |
|---|---|---|
| diffusion_models | денойзеры (сама «модель») | krea2_turbo_int8_convrot, minimax_h3_…_int8 |
| text_encoders | текстовые энкодеры | qwen3vl_4b_fp8_scaled |
| vae | VAE | qwen_image_vae |
| loras | LoRA | стилевые, реализма, персонажа |
| upscale_models | пиксельные апскейлеры | OmniSR ×4, Remacri ×4 |
| checkpoints | старый формат «всё в одном файле» | SDXL Juggernaut |

- **Несколько установок — одна папка моделей.** Файл `extra_model_paths.yaml` добавляет другие папки; в нём должна быть каждая подпапка, которую использует шаблон, иначе ComfyUI «не видит» файл ЗАМЕР.

- **Desktop хранит модели отдельно от программы** — обновление не трогает 100+ ГБ весов. Пути на тестовой машине — в главе [«Железо и файлы»](ch-studio.html#files).

- **Скачивайте из первоисточника**: репозитории Comfy-Org на Hugging Face уже разложены по этим папкам; LoRA — со страницы автора на Civitai.

## Кастомные ноды

Всё, чего нет в ядре, приходит **кастомными нодами** — папками с Python-кодом в `custom_nodes/`. Ставят их через ComfyUI Manager или `git clone`. В книге используются, например, KJNodes (цветокоррекция, SageAttention), Impact Pack (детейлер лица), VideoHelperSuite, Frame-Interpolation (RIFE, FILM), comfyui-krea2edit.

- **Это чужой код на вашем компьютере.** Ставьте ноды известных авторов, смотрите число звёзд и дату обновления.

- **Красная нода в чужом графе** = такой ноды у вас нет. Manager предложит установить недостающие.

- **После установки нужен перезапуск**, а агенту — заново запросить список нод (`/object_info`), иначе он «не видит» новую ноду ЗАМЕР.

## Подграфы и наш стиль workflow

Граф хорошей модели легко разрастается до 40–80 нод. ComfyUI умеет сворачивать часть графа в одну ноду — **подграф** (subgraph) — и выносить на неё только нужные поля. Все workflow этой книги собраны одинаково: на холсте заметка-инструкция, загрузка картинки, **одна нода с полями и переключателями** и сохранение. Двойной клик по заголовку открывает технику внутри.

Переключатели (апскейл, 48 fps, звук, цветокоррекция) стоят на «ленивых» нодах-переключателях: выключенная ветка не считается вовсе. Каталог готовых файлов — [глава «Workflow»](ch-workflows.html).

## Workflow внутри картинки и видео

- **ComfyUI записывает граф в каждый результат**: в метаданные PNG и в MP4. Перетащите такой файл на холст — откроется граф, который его сделал, со всеми настройками и сидом.

- **Два формата JSON.** «Workflow» — с расположением нод, подграфами, заметками (для людей). «API» — плоский список нод с входами (для скриптов): меню Workflow → Export (API).

- **На Civitai** многие картинки несут граф или хотя бы модель, LoRA, сэмплер и сид — так устроены разборы в главе [«Повтор трендов»](ch-trends.html).

## Как агент управляет ComfyUI без мыши

Сервер ComfyUI слушает HTTP (по умолчанию `127.0.0.1:8188`). Всё, что делает кнопка «Run», доступно скрипту: отправить граф в очередь, дождаться результата, освободить память.

| Запрос | Что делает |
|---|---|
| POST /prompt | поставить граф в очередь, ответ — `prompt_id` |
| GET /history/<id> | результат: имена выходных файлов |
| GET /queue | что считается сейчас (проверять перед тяжёлой задачей) |
| GET /object_info | все ноды, их входы и допустимые значения |
| POST /free | выгрузить модели и освободить видеопамять |

### Запуск графа из Python

```
import json, time, urllib.request

URL = 'http://127.0.0.1:8188'
graph = json.load(open('workflow_api.json', encoding='utf-8'))   # Workflow → Export (API)
req = urllib.request.Request(URL + '/prompt', data=json.dumps({'prompt': graph}).encode(),
                             headers={'Content-Type': 'application/json'})
pid = json.load(urllib.request.urlopen(req))['prompt_id']
while True:                                                       # ждём, пока граф посчитается
    hist = json.load(urllib.request.urlopen(f'{URL}/history/{pid}'))
    if pid in hist:
        break
    time.sleep(2)
print(hist[pid]['outputs'])                                       # имена файлов в папке output/
```

- **Кэш.** ComfyUI помнит результаты нод: если поменять только последнюю ручку, пересчитается только хвост графа (обрезка готового видео — 3 с вместо 6 минут) ЗАМЕР.

- **Одна видео-задача за раз.** Два сервера ComfyUI с H3 одновременно делят оперативную память и вдвое замедляют друг друга ЗАМЕР.

- **Сервер — только на 127.0.0.1.** Открытый в интернет ComfyUI — это чужой код по вашей команде. В облаке к нему ходят через SSH-туннель.
