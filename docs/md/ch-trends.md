# 19. Повтор трендов

> EN: Trend replication loop, one page per Civitai post: metadata via the public API, missing files, rebuilt graph, closest copy + two own-subject renders in the same aesthetic; what replicates on the first render and what needs the creator's LoRA.

Каждая страница — один пост: оригинал, что из него удалось вытащить, разбор, workflow с LoRA и наш результат. Цель — чтобы любой понравившийся пост можно было повторить по шагам.

- Метаданные поста берутся из открытого API Civitai без входа в аккаунт.
- Правильный сюжет, но не та манера — значит, вид даёт стилевая LoRA; промпт переписывать бесполезно.
- На каждой странице: копия (поняли ли рецепт) и два своих сюжета (можно ли им пользоваться).

## Как устроен раздел

Петля одна и та же: находим пост, который нравится или в тренде; через открытый API Civitai вытаскиваем модель, LoRA с весами, сэмплер, шаги, cfg, seed и промпт; ставим недостающие файлы; собираем граф на нашем стеке и рендерим несколько seed; кладём рядом с оригиналом и называем разницу. Не больше двух итераций на пост, время каждой записываем: так петля ускоряется от поста к посту.

На каждой странице три наших картинки: **максимально похожая копия** и **два своих сюжета в той же эстетике** — тот же стиль, LoRA и настройки, другой объект. Копия проверяет, поняли ли мы рецепт; свои сюжеты — можно ли этим рецептом пользоваться.

Оригиналы принадлежат их авторам, у каждого стоит ссылка на пост.
