## Главное за минуту

- **Качество LoRA решает отбор, а не объём.** На персонажа хватает 20–60 картинок, на стиль 24–200. Тысячи нужны только для сложных концептов.

- **Большинство креаторов Civitai учат на своих же генерациях:** добиваются вида промптом и стеком LoRA, делают 60–200 кадров, оставляют лучшие 40–50.

- **Подписи пишет VLM-модель** (JoyCaption, Qwen3-VL, Florence-2). Триггер ставят первым. Постоянные черты не описывают, тогда они «прилипают» к триггеру.

- **Готовые бесплатные датасеты есть**, но они нужны для стиля, фона и разнообразия, а не для «своего» персонажа. И у каждого своя лицензия.

## Как креаторы набирают данные: что пишут в постах

Мы разобрали 44 описания LoRA на Krea 2, MOSS, Anima и Illustrious. Источники данных повторяются.

| Источник | Примеры из постов | Для чего |
|---|---|---|
| **Свои генерации** | ta86: ~120 и ~200 своих картинок на две стилевые LoRA («самое долгое — собрать данные»); NIJISIS учит на своих кадрах из Midjourney Niji; RKRRA генерирует ~200 кандидатов на персонажа и оставляет медиану 48 | стиль, вымышленный персонаж |
| **Реальные фото** | 55 RAW-снимков одного города с DSLR; реализм-LoRA из RAW (DNG/ARW/CR2/NEF) без студийного света; 44 кадра из фильмов на «плёнку»; 24 фото для Ektachrome | реализм, плёнка, город |
| **Кадры из видео** | 859 кадров из роликов ради разнообразия поз; персонаж из 5 официальных артов + 8 реалистичных перерисовок + 14 кадров из image-to-video по этим же артам | позы, ракурсы, «доращивание» маленького набора |
| **Большие подборки** | стиль Impasto на MOSS: 1700 отобранных картинок, все переподписаны Qwen-Image-2.1 в той же структуре, в какой пользователь пишет промпт; концепт-LoRA на 1–3 тысячи | сложный стиль или концепт |
| **Кропы без лиц** | одежда, фигура, текстура кожи: лица вырезают, «чтобы LoRA не меняла лицо» | концепты, которые надо совмещать с любым персонажем |

### Правила, которые повторяют все

1. **Разнообразие во всём, кроме цели.** Если на всех кадрах один свет, одна кофта или одна комната, LoRA выучит и их. Меняйте фон, одежду, свет, дистанцию; повторяться должно только то, ради чего LoRA.

2. **Копия копии деградирует.** Учите на синтетике — берите только лучшие ~50 из сотен. Средние кадры передают артефакты дальше.

3. **Пропорции важны:** примерно треть крупных планов, треть средних, треть в полный рост. Без полного роста LoRA «не знает» фигуру.

4. **Подпись = будущий промпт.** Формат: `Триггер, класс. Что в кадре: поза, одежда, место, свет.` Лицо, приметы и цвет волос персонажа не описывают.

5. **Триггер как имя** («Maren Holt»), а не набор букв: Krea читает незнакомое слово как текст и печатает его на книгах и вывесках. Это наша находка из серии 13.

6. **Реальных людей не учат без согласия.** Civitai убрал LoRA реальных людей в мае 2025-го, в США действует Take It Down Act.

## Наш рабочий рецепт: персонаж из одного лица

Так собран датасет Марен (серии 3 и 13). Подробности в главе «Свой персонаж и LoRA».

1. **Hero-кадр**: Krea 2 + реализм-LoRA, фронтальный мягкий свет, все приметы видны.

2. **75 сцен через edit-модели**: Krea Identity Edit V2 держит лицо; Qwen-Edit 2511 — для эмоций и профилей; полный рост — сцена от Qwen + лицо через Identity Edit.

3. **Отбор**: ArcFace ≥ 0.5 к hero, глазами проверяем сторону примет (edit-модели иногда зеркалят), выкидываем повторы одежды и комнат. Осталось 50, потом 47.

4. **Резкие крупные планы примет**: hero + 5 ракурсов. Мелкие детали учатся последними, им нужны чёткие кадры.

5. **Подписи** по шаблону выше, тренировка без регуляризации, утечку гасит DOP (v3).

## Готовые бесплатные датасеты

Проверены по их собственным страницам (октябрь 2026). Зелёная лицензия — можно спокойно, жёлтая — с условиями, красная — только для себя/исследований.

| Датасет | Что внутри | Лицензия | Чем полезен |
|---|---|---|---|
| [PD12M](https://huggingface.co/datasets/Spawning/PD12M) | 12,4 млн фото с подписями, файлы в открытом S3 | CC0 / PD | самый чистый фотореалистичный пул: фоны, места, вещи |
| [Megalith-10M](https://huggingface.co/datasets/madebyollin/megalith-10m) | 9,6 млн ссылок на Flickr, 4 готовых набора подписей (Florence-2, InternVL2…) | CC0 / PD | фото «как с телефона и камеры», нужен img2dataset |
| [Mitsua art-museums-pd-440k](https://huggingface.co/datasets/Mitsua/art-museums-pd-440k) | ~440 тыс. работ из Smithsonian, Met, Кливленда и Чикаго | CC0 (подписи CC BY) | стилевые LoRA на классике: гравюра, акварель, масло |
| [DOCCI](https://huggingface.co/datasets/google/docci) | 14,8 тыс. фото с длинными описаниями, написанными людьми | CC BY 4.0 | эталон длинных подписей: учиться писать caption |
| [SFHQ-T2I](https://github.com/SelfishGene/SFHQ-T2I-dataset) | 122,7 тыс. синтетических лиц 1024 px (Flux, SDXL, DALL-E 3) + промпты | MIT, часть Flux-dev — некоммерч. | лица без реальных людей: регуляризация, тесты утечки |
| [CommonCatalog CC-BY](https://huggingface.co/datasets/common-canvas/commoncatalog-cc-by) | 14,6 млн фото Flickr с подписями BLIP-2 | CC BY: указывать авторов | большой общий пул с готовыми подписями |
| [DALL-E 3 1M (ProGamerGov)](https://huggingface.co/datasets/ProGamerGov/synthetic-dataset-1m-dalle3-high-quality-captions) | ~1 млн синтетических картинок с длинными подписями CogVLM, 565 ГБ | MIT | концепты и стили, примеры хороших подписей |
| [The Met](https://github.com/metmuseum/openaccess) · [Smithsonian](https://www.si.edu/openaccess) · [Rijksmuseum](https://data.rijksmuseum.nl) | сотни тысяч оцифровок музейных работ | CC0 | собрать свой стилевой набор из 50–200 работ одного мастера |
| [FFHQ](https://github.com/NVlabs/ffhq-dataset) | 70 тыс. реальных лиц 1024 px | BY-NC-SA | только для себя: тесты, регуляризация |
| Danbooru2023 | ~8 ТБ аниме-артов с тегами | серая зона (чужие арты) | понять теги, на которых учились Illustrious/NoobAI; учить на нём — риск |

**Осторожно:** Unsplash Lite разрешён только для внутреннего использования, без распространения; лицензии Pexels и Pixabay ничего не говорят про обучение ИИ.
