Видео: что получилось

В роликах есть звук, его генерирует сама H3 по строке overall_soundscape. Включи его в плеере.

Длина видео и склейка клипов

Те же настройки победителя (768×960, турбо 8 шагов, shift 8), длинные раскадровки, одно действие на 1,5–2,5 с. По правилу ноды число кадров должно быть 17k+5, обученный диапазон H3 — 124–362 кадра (5–15 с).

  • Как работает склейка 03c. Последние 22 кадра и звук предыдущего клипа ставятся якорем (нода MiniMaxH3AddGuide) в начало нового. Перекрытие обрезается, части склеиваются в один mp4. Результат можно подать на вход снова.
  • Правило: до 9 с — один клип (03); 10–12 с — один клип (03b) или две части; больше 12 с — цепочка частей по 5–8 с через 03c.
  • Время растёт быстрее длины: 6 → 9 с даёт ×2 времени на ×1,6 кадров. VRAM не растёт (динамическая загрузка), RAM держится до 59 ГБ.

H3 Eros Max против официальной H3

Одетая сцена с медитацией, кадр из секции «Фигура», один сид и одна раскадровка, 768×960, 124 кадра. Eros Max beta5 — дообученный чекпойнт сообщества из образца с Civitai (int8, уже турбо) + LoRA VBVR 0.25.

  • Для одетых сцен бери 03. Eros Max не быстрее и мягче. Его единственный плюс — анатомия, которую официальная H3 размазывает.
  • В 05 теперь по умолчанию shift 8. Старая версия сохранена как 05_video_h3_erosmax_i2v_baseline.
  • Пальцы плывут, когда руки трогают тело в последней секунде. Действие с касанием ставь в середину клипа, а заканчивай спокойным удержанием. В negative: fused fingers, missing fingers.
  • Не запускай H3 в Desktop, пока считает агент. Два ComfyUI с H3 оставили 3 ГБ свободной RAM, время выросло вдвое.
